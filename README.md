# ExamGuard 쉬운 화면 (스마트안경 점검 도우미)

시험 감독위원이 **설명 없이 바로 쓸 수 있게** 화면을 단순하게 바꾼 ExamGuard 수정본입니다.

> **원본:** [epoko77-ai/examguard](https://github.com/epoko77-ai/examguard) (MIT 라이선스, 이승현 님 개발)
> 탐지 방식과 판단 규칙은 원본 그대로이고, 화면·기록 기능만 덧붙였습니다. 원본 설명은 [docs/ORIGINAL_README.md](docs/ORIGINAL_README.md)에 있습니다.

## 무엇이 달라졌나

| 구분 | 원본 | 이 수정본 |
| --- | --- | --- |
| 첫 화면 | 3개 모드 + 보조 도구가 한 화면에 | **4단계 안내** (준비 → 기기 찾기 → 안경 보기 → 기록) |
| 용어 | BLE, RSSI, 광고 패킷 | 쉬운 말 (전문가 기능은 "전문가 화면"에 그대로) |
| 결과 표시 | 표 + 분류 필터 | **신호등 카드** + 다음에 할 일 한 줄 |
| 기록 | 새로고침하면 사라짐, JSON만 | **자동 저장**, 인쇄용 기록지(PDF), 엑셀용 파일(CSV) |
| 연습 | 연습 모드 | **시연 모드**: 블루투스·안경 없이 끝까지 눌러보기 |

## 바로 쓰기

- 주소 그대로 열면 쉬운 화면입니다.
- 주소 뒤에 `?demo=1` → 시연으로 바로 시작
- 주소 뒤에 `?ui=pro` → 원본과 같은 전문가 화면

기기 찾기(블루투스)는 **안드로이드 Chrome** 또는 **PC의 Chrome·Edge**에서만 됩니다. 아이폰은 안경 보기·도감·기록만 쓸 수 있습니다.

## 꼭 알아 둘 한계 (원본과 같음)

- 교실 전체를 자동으로 훑지 못합니다. 목록 창에서 **고른 기기만** 기록합니다.
- 전원이 꺼진 안경, 이름을 바꾼 기기는 못 찾을 수 있습니다.
- 실제 스마트안경으로 **탐지 정확도를 검증하지 않은 시제품**입니다.
- 이 도구는 판정하지 않습니다. 부정행위 여부와 소지자 확인은 시험 주관기관 절차에 따릅니다.

## 고쳐 쓰기

Node.js 22.18 이상이 필요합니다.

```
npm ci
npm run dev      # 미리 보기
npm test         # 단위 테스트
npm run build    # dist/ 생성
```

쉬운 화면 관련 파일은 `src/lib/easy.ts`(문구·CSV·저장), `src/easy.css`(모양), `src/main.ts`의 "쉬운 화면" 구역입니다.
