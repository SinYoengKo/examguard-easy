# 스마트안경 점검 도우미 — 사용법 · 시연 순서 · 유지보수

## 1. 한 장 사용법 (감독위원용)

| 단계 | 할 일 | 화면에서 누를 것 |
| --- | --- | --- |
| 1. 준비 | 휴대전화 끄기, 전자기기 걷기, 허용 장비 확인 | 3가지를 하나씩 눌러 체크 → **다음** |
| 2. 기기 찾기 | 걷은 뒤에도 켜져 있는 블루투스 기기 확인 | **안경 종류만 찾기** → 목록 창에서 기기 하나 고르고 ‘페어링’ |
| 3. 안경 보기 | 의심되는 안경을 교탁에 놓고 살펴보기 | **카메라로 살펴보기** 또는 **도감과 비교하기** |
| 4. 기록 | 확인한 사실을 남기기 | **기록지 인쇄 · PDF 저장** 또는 **엑셀용 파일 받기** |

### 카드 색의 뜻

| 색 | 뜻 | 할 일 |
| --- | --- | --- |
| 빨강 | 스마트안경일 수 있음 (이름 단서) | 기관 절차에 따라 안경을 교탁에 놓게 하고 3단계에서 확인 |
| 노랑 | 어떤 기기인지 모름 | 감독 장비인지 확인, 아니면 주변 살피기 |
| 회색 | 안경이 아닌 전자기기 이름 | 전원·수거 여부 확인 |
| 초록 | 확인 끝 | 없음 |

### 어떤 기기로 여나

| 기기 | 브라우저 | 기기 찾기(2단계) | 안경 보기·기록 |
| --- | --- | --- | --- |
| 안드로이드 휴대전화 | Chrome 앱 | 가능 | 가능 |
| 윈도우·맥 PC | Chrome 또는 Edge | 가능 (블루투스 필요) | 가능 |
| 아이폰·아이패드 | Safari | **불가** | 가능 |

카카오톡·네이버 안에서 열렸다면 주소를 복사해 Chrome 앱에 붙여 넣으세요.

## 2. 시연 순서 (약 1분, 블루투스·안경 없이)

주소 뒤에 `?demo=1`을 붙여 열면 바로 시연이 시작됩니다. PC·아이폰 어디서나 됩니다.

1. 화면 위에 노란 띠 **“시연 중”** 이 보이는지 확인합니다.
2. **준비 3가지**를 하나씩 눌러 체크하고 **다음**을 누릅니다.
3. **안경 종류만 찾기**를 누릅니다. → 빨강 카드(가상의 Ray-Ban Meta)가 생깁니다.
4. **모든 기기 보기**를 누릅니다. → 노랑·회색 카드가 추가됩니다.
5. 카드의 **허용 장비 / 더 확인 필요 / 실물 확인 끝**을 눌러 봅니다. 색이 바뀝니다.
6. **다음** → 안경 그림을 보고, **도감과 비교하기**를 눌러 봅니다.
7. **다음** → **기록지 인쇄 · PDF 저장**을 눌러 기록지를 봅니다. (“시연용 예시”라고 찍힙니다)
8. **시연 끝내기**를 누릅니다. 시연 기록은 남지 않습니다.

### 시연 때 같이 말씀드릴 점

- 화면에 나오는 기기는 **가상 예시**입니다. 실제 탐지 결과가 아닙니다.
- 실제 현장에서는 목록 창에서 **고른 기기만** 기록됩니다. 교실 전체 자동 탐지가 아닙니다.
- 실제 스마트안경으로 정확도를 검증하지 않은 시제품입니다.

## 3. 체크리스트

### 시험 전날

- [ ] 쓸 기기에서 주소를 한 번 열어 본다 (인터넷 연결 상태)
- [ ] 안드로이드는 Chrome으로 열리는지 확인한다
- [ ] 블루투스·카메라 권한을 허용한다
- [ ] 시연 모드로 4단계를 한 번 눌러 본다

### 시험 당일

- [ ] 준비 3가지를 체크한다
- [ ] 기기 찾기는 수거가 끝난 뒤에 한다
- [ ] 빨강 카드는 기관 절차에 따라 실물을 확인한다
- [ ] 기록지를 인쇄하거나 파일로 받는다
- [ ] 끝나면 ‘새 점검 시작’으로 기록을 지운다

## 4. 유지보수 (후임자용)

### 파일 구조

| 파일 | 역할 | 고쳐도 되나 |
| --- | --- | --- |
| `src/lib/easy.ts` | 카드 문구, 엑셀용 CSV, 자동 저장 검사 | 가능 (문구는 여기서) |
| `src/easy.css` | 쉬운 화면 모양, 인쇄 기록지 모양 | 가능 |
| `src/main.ts` 의 “쉬운 화면” 구역 | 단계 이동, 시연, 기록지 | 가능 (주의) |
| `src/lib/device-hints.ts` | 기기 이름으로 안경 후보를 가르는 규칙 (원본) | 실기기로 확인한 이름만 추가 |
| `src/lib/bluetooth-scan.ts` | ‘안경 종류만 찾기’에 쓰는 이름 목록 (원본) | 위와 같이 |
| `tests/easy.test.ts`, `tests/e2e/easy.spec.ts` | 쉬운 화면 테스트 | 기능을 바꾸면 같이 수정 |

### 자주 하는 수정

| 하고 싶은 일 | 고칠 곳 |
| --- | --- |
| 카드 설명 문구 바꾸기 | `src/lib/easy.ts` 의 `easyCard` |
| 준비 3가지 이름 바꾸기 | `src/lib/easy.ts` 의 `PREP_LABELS` (기록지·CSV용), 화면 글자는 `src/main.ts` 의 `preflight-grid` |
| 새 안경 기종 이름 추가 | `device-hints.ts` 의 `glassesNames` + `bluetooth-scan.ts` 의 `namePrefixes` (둘 다) |
| 기록지 양식 바꾸기 | `src/main.ts` 의 `buildSheet`, 모양은 `src/easy.css` 의 `@media print` |

### 올리는 방법 (GitHub Pages)

1. 고친 뒤 `npm test`, `npm run build` 가 통과하는지 확인합니다.
2. `main` 브랜치에 올리면 GitHub Actions가 테스트 후 자동으로 배포합니다.
3. 저장소 Settings → Pages → Source 가 **GitHub Actions** 여야 합니다.

### 문제가 생기면

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 찾기 버튼이 눌리지 않음 | 준비 3가지 미체크, 또는 지원하지 않는 브라우저 | 1단계 체크, 안드로이드 Chrome·PC Chrome/Edge로 열기 |
| 목록 창이 비어 있음 | 이름이 다르거나 전원이 꺼진 기기 | ‘모든 기기 보기’로 다시, 눈으로 확인 |
| 엑셀에서 한글이 깨짐 | 다른 프로그램으로 다시 저장함 | 받은 파일을 그대로 엑셀로 열기 (UTF-8 BOM 포함) |
| 예전 기록이 계속 보임 | 자동 저장 | 4단계의 ‘새 점검 시작’ |
| 배포가 안 됨 | Actions 테스트 실패 | 저장소 Actions 탭에서 실패한 단계 확인 |

## 5. 확인 필요 사항

| 항목 | 이유 |
| --- | --- |
| 시험장에서 수험자 주변 기기를 블루투스로 확인해도 되는 근거 | 공단 공식 절차가 아니므로 본부·소관 부서 검토 필요 |
| 실제 스마트안경에서의 탐지 여부 | 실기기 검증 없음 (원본 포함) |
| 아이폰(Safari)·실제 안드로이드 기기 동작 | 이 수정본은 PC용 Chrome 자동 테스트로만 확인 |
